# little-reef（小海底）現狀證據包

## 1. 一句話定位

「用專注時間養出一片小海底」——一個安靜的桌面專注計時器（番茄鍾），每完成一輪專注，水族館裡的水草就長高一點，偶爾有魚、蝦、螃蟹來訪；帶訪客圖鑑、20 種離線背景音。（來源：README.md）

## 3. 功能現狀（來源：README.md 功能節 + CHANGELOG.md）

### 3.1 專注計時
- 預設 25 分鐘專注 / 5 分鐘休息，可在設定調整，新時長從下一輪生效
- 開始、暫停、繼續、提前結束；任務名稱可選填；空格鍵開始/暫停
- 計時由 Go 後端負責，介面隱藏不影響計時；休眠自動暫停（掛起 >5 秒），休眠時間不計入專注
- 正常退出儲存並暫停；重開後保持靜音需手動繼續；每 30 秒自動存檔，重要操作立即存檔
- 提前結束記錄已投入時間但不增加成長；完成休息也不增加成長
- 完成提示音可單獨開關；靜音時仍有文字提示和系統通知
- 日記保留最近 1000 條，介面顯示最近 30 條；總時長和成長永久保留

### 3.2 成長與訪客（核心差異化）
- 每完成一輪：水草長高；每三輪多一株植物；長滿後數量封頂，畫面不擁擠
- 第一輪必定遇見小丑魚；之後每完成一輪有 1/3 機率遇見訪客
- 訪客物種：**15 種** = 4 種魚 + 6 種蝦 + 5 種蟹（小丑魚、清潔蝦、火焰蝦、油彩蠟膜蝦、槍蝦、皮皮蝦、琵琶蝦、寄居蟹、翡翠蟹、瓷蟹、箭蟹、梭子蟹等）
- 出場規則：沒見過的先來；15 位都見過之後老朋友再來；圖鑑永久儲存（來源：README + CHANGELOG 0.3.0 + git log）
- 每種生物按真實物種繪製；魚擺尾、懸停、轉身、彼此保持距離；蝦蟹在沙地石頭爬行、躲石縫/洞/螺殼，同一時間只有幾隻在外活動
- 每次休息可以喂一次魚：魚食慢慢下沉，魚吃剩的落沙地由蝦蟹撿走；不照料也不會死魚、不扣裝飾
- 圖鑑畫像與水缸生物同一套畫法

### 3.3 背景音（20 種）
- 海浪、雨聲、雷雨、溪流、氣泡、煮沸、深海、風聲、篝火、森林、夏日、夏夜、沙漠、晨間、時鐘、木魚、咖啡館、卡農、車流、粉紅噪音
- 19 種為 CC0 公共領域實地錄音（Freesound，卡農為美國空軍樂團作品），隨程式打包，播放不聯網；粉紅噪音即時合成
- 無接縫迴圈（等功率交叉淡化）；時鐘/木魚接縫落在敲擊之間；卡農播完停頓約 2 秒；其餘隨機起點
- 開始/繼續專注時按開關自動播放；暫停/結束/完成停止；休息預設靜音；首次不自動出聲；重啟不自動播放
- 合計約 27 MB 錄音，程式體積約 41.9 MB（來源：docs/superpowers/plans/2026-10-11-real-ambience-recordings.md）

### 3.4 桌面體驗
- 桌面掛件模式（緊湊置頂小窗，400×350）+ 完整視窗（1100×800）；掛件與展開視窗留在當前顯示器（來源：main.go）
- 收起到選單欄（托盤）；選單欄小魚專注時輕輕游動、暫停/休息停住
- 全域快捷鍵 `CmdOrCtrl+Shift+A`
- 系統「減少動態效果」時海底與選單欄保持靜態，計時與背景音正常（0.3.0 起）
- 自動更新：每 4 小時檢查一次（0.2.3 起），托盤/設定可手動「檢查更新」；簽名更新包（0.2.2 起）
- 回饋入口：計時設定 + 托盤右鍵選單「問題回饋」（0.2.1 起）
- 更新簽名私鑰不入庫（最新提交），MyGo 0.6.0 升級（最新提交）

### 3.5 技術棧（來源：README + go.mod + mygo.json + main.go）
- Go 1.27.1 + MyGo 0.6.0 桌面框架；`//go:embed web` 內嵌前端，無 JS 構建、無需 Bun、無前端依賴
- macOS 用 WKWebView；瀏覽器模式 `-web 127.0.0.1:4173` 僅監聽迴環
- 存檔 `aquarium.json`：macOS 在 `~/Library/Application Support/小海底`；`-data-dir` 可指定
- 自動更新：GitHub Releases + 簽名公鑰（mygo.json updates 配置）
- 測試：Go 測試（計時/存檔/訪客/錄音/動態效果）+ Node 端到端測試（tests/*.test.mjs）
- 包名/識別符號：dev.mygo.examples.aquarium（注意：仍是 mygo 示例風格 identifier，見 mygo.json——「推斷」：正式產品化時可能需要獨立 bundle id）
