主題一：水墨蘭亭（cn-shuimo）

1. 主題名稱與代號

水墨蘭亭 · 代號 cn-shuimo

2. 氣質定位

「把水族箱養在一張宣紙上」——一套文人畫式的水下世界。墨分五色，留白即水：魚是紙上一點濃墨，珊瑚是枯筆枝幹，氣泡是虛圈。整套介面只有一個暖色（硃砂），用於極少數需要點睛的地方，其餘全靠墨階深淺說話。安靜、疏朗、不爭。

3. 適用場景

長時間深度專注（寫作、閱讀、連續編碼）的首選主題；夜間想收斂心神、不願被色彩打擾的時刻。適合偏愛極簡與大量留白的使用者——它是最接近「一張安靜的紙」的主題。

4. 色彩體系

色相邏輯：全畫面無彩色墨階（約 40°~50° 的暖灰基調）+ 唯一暖色硃砂做強調，即傳統設色的「萬墨叢中一點朱」。文字對比度（實測）：textPrimary 對 bgBase 11.15:1（AAA），textSecondary 對 bgBase 4.66:1（AA），accent 對 controlBg 4.62:1（AA）。

5. 水族箱背景畫面

  • 構圖（遠中近三層）：上 1/3 為大面留白「水天」，僅在頂緣有一道月白天光亮帶；中景偏左放一株大型枯筆鹿角珊瑚，偏右 2~3 筆蘭葉水草（疏密呼應，忌對稱）；底部 1/5 為沙洲淺赭，用橫向枯筆皴擦出 3~4 道深淺筆觸。
  • 光照：頂部柔和漫射天光，色溫 4500K 偏暖；不出現體積光柱與光斑——留白主題裡光斑即噪音。
  • 水體通透度：極高。留白本身就是通透，唯一的深淺變化是從 bgGradient 到 bgBase 的自下而上漸隱。
  • 靜態元素：宣紙底紋（512×512 可平鋪 tile，紋理對比度極低）、沙洲、珊瑚。
  • 動態元素：2~3 尾墨魚、苔墨水草 ±3° 緩擺、每屏不超過 3 個空心墨圈氣泡。

6. 魚類與生物視覺

造型語言：輪廓由「筆觸」構成——起筆重、行筆輕、收筆飛白（透明度漸隱），全部生物帶 1px 淡墨輪廓，不用任何高光材質。

  • 墨鱗鯉（代表魚 1）：紡錘形，體長約為畫面寬 1/10；背部濃墨 #2B2722 一筆鋪出，向腹部過渡為 60% 透明淡墨，尾鰭兩筆撇出、末端飛白（opacity 0.4）；單尾或兩尾同遊，巡遊速度為預設主題的 0.3×，路徑為長弧線、幾乎不轉向。
  • 齊白石式墨蝦（代表魚 2）：軀幹 6 節、節節淡墨（#6E6A5C @70% 透明度），雙長鬚為 0.5px 細線向前伸出體長 1.5 倍；行為以「停」為主——掛在珊瑚枝上靜置，每 20~40 秒一次後退彈跳。
  • 淡墨蟹（代表魚 3）：殼用濃墨點染、螯足用淡墨，趴在沙洲上以 0.1× 速度橫向緩爬，是畫面中「最慢的元素」。
  • 珊瑚/水草：珊瑚為枯筆鹿角狀，主幹 2.5px、末梢 1px，枝頭留白斷筆；水草用蘭葉描「一筆一葉」，葉尖飛白。
  • 群遊建議：不群遊。文人畫裡魚永遠只有兩三尾，本主題生物數量硬上限 3，遵循「疏可走馬」。

7. 介面控制元件樣式

  • 選單欄圖示：template 單色剪影，16×16pt，一條 S 形單筆魚輪廓（一筆畫出，不斷線）；專注中 3 幀橫擺動畫（位移 ±2px，1.2s/迴圈），暫停/休息時停幀——與現有預設主題行為一致。
  • 計時器卡片：宣白 #FAF7EF @90% 不透明，圓角 10pt，描邊 1px #C6BFAE，陰影 0 2px 8px rgba(51,48,43,0.12)；卡片內部計時數字用濃墨，左上角狀態點 6pt（進行中松煙綠/休息赭墨）。
  • 按鈕：高 28pt，圓角 8pt，描邊 1px #C6BFAE，預設底 controlBg，hover 底換 bgBase，按下不透明度降至 80%。
  • 進度環：環寬 4pt，底環 #C6BFAE，走針 #4E6E5D；完成時不彈動畫綵帶，只做一件事——一枚 16×16pt 硃砂印章（印文可用「休」字）在環心 400ms 內淡入並輕輕落下（位移 2px），隨後常駐本次記錄條目。
  • 開關：36×22pt 膠囊，圓角 11pt，關閉態描邊 #C6BFAE + 底 controlBg，開啟態填充 #4E6E5D。
  • 卡片（統計/列表）：圓角 12pt，其餘同計時器卡片；卡片標題左側加一枚 8pt 淡墨方印作裝飾錨點。

8. 字型建議

  • 標題："Kaiti SC", "LXGW WenKai", "Songti SC", serif（楷體的手寫感呼應筆墨；未裝 LXGW WenKai 時優雅回退，不依賴安裝）
  • 正文："PingFang SC", "Hiragino Sans GB", sans-serif
  • 計時數字："SF Mono", "Menlo", monospace（等寬數字避免跳動；此主題刻意不用書法體做數字，保證專注中讀數零負擔）

9. 動效與聲音

  • 緩動：cubic-bezier(0.33, 0, 0.2, 1)——偏慢的緩入緩出，模擬墨跡在水中沉降。
  • bubbleDensity：0.2×（每屏 ≤3 個，空心墨圈）；driftSpeed：0.3×；水草擺幅 ±3°、週期 6s。
  • 環境音（可選、預設關）：極低音量古琴泛音 + 一滴硯臺水聲，無旋律迴圈，音量上限內建為系統 20%。
  • 減少動態效果相容：開啟後魚全部停靠為中景懸停姿勢、水草垂直、氣泡消失、印章淡入改為無位移直接顯隱；計時數字變化保留 150ms 純淡入（不屬動態效果，屬狀態提示）。

10. 落地備註

  • Token 對映：bgBase/bgGradient/waterLight/sand（背景層 4 token 原值直填）；coral/fish/seaweed/bubble（生物層 4 token）；accent/timerActive/timerPause/controlBg/controlBorder/textPrimary/textSecondary/menuIcon（UI 層 8 token 全部使用）；bubbleDensity=0.2、driftSpeed=0.3、easing=墨沉曲線、ambientAudio=guqin-drip。
  • 資產清單：魚 sprite 3 套（墨鱗鯉/墨蝦/墨蟹，各含游動幀 3 幀 + 懸停幀 1 幀）；珊瑚貼圖 2 套（枯筆鹿角大/小，各含成長 3 階段）；水草貼圖 1 套（蘭葉描，3 幀擺動）；選單欄圖示 1 枚（template PDF）；硃砂印章 PNG 1 枚；宣紙紋理 tile 1 張（512×512）。
  • 特殊實現：留白區域就是背景層本身，禁止疊加任何漸變光斑/體積光粒子；所有透明度透過 CSS 變數掛 token，不硬編碼；飛白效果用 sprite 內建 alpha 通道實現，不做執行時濾鏡（省效能）。

「把海底燒進一隻梅瓶裡」——鈷藍在瓷白釉面上暈散，魚是纏枝紋間游動的一筆青花。整套畫面只有兩種顏色：瓷的白與鈷的藍，最多再借一點瓷器底足的露胎赭。清涼、規整、雅而不冷。

  • 構圖：上 2/5 為釉白向天青沉的極緩垂直漸變（模擬釉層厚度的感覺，漸變跨度大、對比弱）；水面下 1/6 處一條 45° 入射的月白高光帶（柔和橢圓羽化，非鏡面反光）；中景左右各一組纏枝珊瑚（左高右低，呼應不等邊構圖）；底部 1/6 露胎赭沙地，邊緣做一圈 2px 的「釉面垂流」過渡（青釉色滴垂入沙地的界線）。

主題二：賽璐璐（cm-cel）

1. 主題名稱與代號

賽璐璐，代號 cm-cel。

2. 氣質定位

一句話定位：90 年代手繪動畫裡那一格清澈的淺海，吉卜力式的平塗和光柱。顏色是分層的、乾淨的，每種顏色只有「亮面/陰影一階」兩個色階，像逐幀畫在賽璐璐片上。明亮但不飽和過度，光柱柔和、水草緩緩搖——三套中最接近現有寫實主題的「安靜陪伴」氣質，是卡通風裡的預設安全款。

3. 適用場景

  • 首選入門卡通主題：想要輕鬆一點、又不希望風格突變太大的使用者
  • 清晨/上午的高質量專注時段，喜歡日系動畫審美的使用者
  • 桌面偏淺色桌布、或需要長時間掛在水族箱前發呆放鬆的使用者（明度分佈均勻，長時間注視不疲勞）

主題三：墨線（cm-ink）

1. 主題名稱與代號

墨線，代號 cm-ink。

2. 氣質定位

一句話定位：一本攤開的速寫本，海底是幾筆炭墨勾出來、再淡淡暈了一點水彩。大面積留白，水用弧線表示而非色塊，魚像日記本里的小插圖。三套中最安靜、紙感最強的一套，色彩從不鋪滿，永遠只是墨線的淡彩註腳。它把「無壓力」推到極致：連顏色都不著急。

3. 適用場景

  • 深度專注、夜間或需要最低視覺干擾的時段；對明快色也嫌吵的使用者
  • 喜歡手賬、速寫、獨立漫畫審美（如《海獸之子》線稿、《一人之下》水墨插頁氣質）的使用者
  • 桌面本身色彩豐富（照片桌布）時，墨線主題的留白與任何桌布都不打架

色相邏輯：藍（背景/魚）→ 紫（珊瑚）→ 粉（暫停點綴）做同冷調色相過渡，椰果白沙地負責接地；所有生物層顏色以 80~85% 不透明度 + 同色 100% 描邊 2px 呈現「果凍半透明」統一質感。timerActive 海鹽墨藍與背景拉開明度差而非依賴飽和度。 對比度（實算）：深海藍黑 #2F3B4A / #EAF4F6 = 10.2:1；藍灰 #56697D / #EAF4F6 = 5.1:1 ✓；海鹽墨藍 #3F7A93 大號數字 / #EAF4F6 = 4.3:1 ✓；蘇打藍 #4E96B4 進度環於雲霧白 #FDFFFF 上 = 3.3:1 ✓。

5. 水族箱背景畫面

  • 遠景（0~40%）：淡水彩藍 #EAF4F6，底部 1/4 漸入荔枝霧紫 #E6DEF0；頂部兩條平行玻璃淺藍 #BFE0EE 折射光帶（各寬 120px、傾角 8°、間距 90px、羽化 36px），不透明度呼吸 0~7%、週期 10s、兩帶相位差 2s——像水面對流光，極慢。
  • 中景（40~75%）：右側「水彩葡萄珊瑚」——圓球簇 5~7 球（直徑 12~28px 不等，交錯填充葡萄果凍 #C3A6E0 與藍莓果凍 #9DB8E8，每球 85% 不透明度 + 同色 100% 描邊 2px，球間疊加處透明度疊加出更深的葡萄色）；左側「果凍草」4~6 條半透明色帶（寬 16px、高 100~140px、水彩藍 #8FC3E8 40% 不透明度，頂端圓頭），隨流 ±4° 擺動、週期 5s。
  • 近景（75~100%）：椰果白 #F4F1E4 平緩沙地（起伏 ≤30px），零散幾粒圓形椰果粒（#FDFFFF，直徑 6~10px）。
  • 專屬動態：中景一束極慢的「果凍折射」——珊瑚球簇整體做 0.5% 尺度呼吸（週期 6s），模擬果凍的微顫；此動效在「減少動態效果」下取消。

6. 魚類與生物視覺

造型語言：圓潤輪廓 + 半透明填充（80~85% 不透明度）+ 同色系 100% 描邊 2px 是本主題的統一基因；所有生物帶一枚白色不規則橢圓高光（約體長 15%，右上角），是「果凍感」的來源；腮紅統一荔枝粉 #D99AA6 40%。

代表生物（3 套 sprite）： 1. 果凍水母（主角，非魚但作為主題簽名）：葡萄果凍 #C3A6E0 85% 半透明傘體（半圓、直徑 56px、底邊圓角 8px），下襬 4~6 條圓頭短觸鬚（描邊 4px、長 20~30px）；垂直漂浮 ±8px、週期 4s，水平漂移 3px/s，傘體每 4s 完成 3% 的收縮-舒張（推進感，極緩）。 2. 蘇打小魚：水彩藍 #8FC3E8 80% 紡錘偏橢圓身體（約 40px），背部一道白色高光弧（描邊 3px），尾鰭半圓。群遊：4~6 條，縱向鬆散排布在光帶下方（像被光照託著），間距 2× 體長，速度 8px/s，相位差 0.4s。 3. 玻璃蝦：近乎透明——#FFFFFF 40% 填充 + 冰藍灰 #8FB8C9 描邊 2px 的彎月形蝦（約 40px），貼沙地爬行 3px/s，是「找到它」的安靜彩蛋。

游動節奏總則：全主題最慢——水母主題本身就是「漂浮」而非「遊」，與無壓力原則天然契合。

7. 介面控制元件樣式

  • 緩動：cubic-bezier(0.42, 0, 0.58, 1)；水母漂浮為正弦疊加，無回彈。
  • 氣泡：8~12 枚（三套中最高，因氣泡本身透明、視覺密度低），直徑 2~6px，上升 7px/s。

主題落地框架

本章節為全專案唯一一份，對中國風、卡通漫畫風、可愛風三大家族以及現有寫實預設主題同樣生效。

Token 骨架最終版（在共享骨架上做 4 處修訂，其餘原樣保留）：

  1. 新增 meta 層：themeId / displayName / styleFamily / version / minAppVersion / supportsDarkAppearance / reduceMotionFallback——主題的自描述資訊不散落在程式碼裡。
  2. 生物層 token 支援成長階段：coral / seaweed 增加可選 stages 陣列欄位（如 "coral": ["#幼","#中","#成"] 或貼圖 grow-1..3），與珊瑚成長玩法對齊；寫實主題同樣補齊此欄位。
  3. 動效層增加兩個守門 token：bubbleDensity 與 driftSpeed 增加全域上限校驗 ≤1.0×預設值（預設值即寫實主題的 1.0×；卡通/可愛風交付的「同屏 N 顆」等絕對值按 1080p 視窗折算），ambientAudio.defaultOn 強制為 false——把「無壓力」原則變成 schema 級約束，任何主題包超限直接校驗失敗。
  4. UI 幾何按家族常量管理：圓角/尺寸/環寬不進 token（見 d 節），token 只管顏色、材質、密度與緩動。

相容現有寫實預設主題：寫實主題作為 themeId: "reef-realistic"、styleFamily: "realistic" 納入同一目錄與同一 token 契約——把現在硬編碼在 web 前端裡的顏色/速度值抽取成它的 theme.json（此為重構動作，不改任何視覺表現）；其餘主題未提供的 token 允許回退繼承 reef-realistic 的值（繼承機制），這樣新主題可以只寫差異項，不必每次填滿全部 token。代號名稱空間約定：中國風 cn-*、卡通漫畫風 cm-*、可愛風 ct-*、寫實 reef-*（預設），均為小寫連字元。

b) 切換入口建議

候選入口 結論 理由
選單欄下拉子選單（推薦主入口） ✅ 採用 選單欄圖示是唯一常駐入口，點開即可切、切完即走，全程不彈視窗、不奪焦點，最符合「不打斷專注」；實現成本最低
設定面板主題頁（推薦輔入口） ✅ 採用 承載完整列表：主題名 + 縮略預覽 + 一句氣質描述；首次探索使用者從這裡選
右鍵水族箱快捷選單 ❌ 不推薦 水族箱視窗常在背景，右鍵路徑不穩定；且容易在「看魚」時誤觸彈選單，驚擾感與產品氣質相悖
懸浮快速切換球 ❌ 不推薦 額外常駐 UI = 違反無壓力原則

c) 切換的工程注意事項

  1. 主題是純表現層，永不碰資料：珊瑚成長、到訪生物、專注記錄全部存於 aquarium.json，與主題無關。切換 = 重綁 CSS 變數 + 替換 sprite 引用，嚴禁觸發任何存檔讀寫——這是本功能最重要的一條紅線，迴歸測試必含「切換 100 次後 aquarium.json 位元組級不變」。
  2. 資產載入與快取：主題包惰性載入，首次切換時舊主題繼續顯示、新包在背景預載（魚 sprite 建議合入紋理集減少 IO）；已載入包 LRU 快取上限 3 個，防止常駐記憶體隨主題數膨脹；webview 靜態資源沿用現有快取機制，theme.json 帶版本號做快取鍵。
  3. 深色模式/系統外觀相容：本批九套主題均為淺色（紙絹/奶昔/印刷底）主題，主題自帶外觀基準、不隨系統深色翻轉（meta 中 supportsDarkAppearance: false 顯式宣告）；選單欄圖示走 template image 由系統自動適配深淺選單欄——這也是各主題 menuIcon 都定義為 template 的原因。深色變體留給後續迭代，不做執行時自動反轉（紙絹色反轉會出現「夜觀書畫」的怪異負片）。
  4. 切換過渡動效：600ms 交叉淡入——新主題背景層先入，生物層 sprite 逐個換裝（避免「集體閃現」）；開啟「減少動態效果」時直接硬切、無過渡。切換本身不附帶任何慶祝性動效（無水花、無波紋）。
  5. 命名與目錄：見 a 節結構；themeId 全小寫連字元、與目錄名嚴格一致；version 用 semver，破壞 token 契約升 major、加資產升 minor、改色值升 patch；theme.json schema 建議用 Go 側 struct 定義並生成 TypeScript 型別給 bindings.ts，保證兩端一致。

d) 主題間一致性規則

  1. 佈局與行為不變：計時邏輯、選單結構、卡片資訊層級、「無壓力」文案（不打卡、不催促）對所有主題完全一致；主題只替換 token + 資產 + 文字字型棧 三樣東西。
  2. 幾何基線按風格家族定義，家族內恆定：控制元件幾何是家族級常量、不進主題包、同一家族內切主題不得改變——本方案三大家族各自交付的基線為：中國風（選單欄 16×16pt、按鈕高 28pt、進度環寬 4pt、卡片圓角 10pt、開關 36×22pt）、卡通漫畫風（選單欄 22pt、按鈕高 34~36pt、卡片圓角 14~20pt、開關 44×26pt、進度環 3~12pt）、可愛風（按鈕高 32px、卡片圓角 16px、開關 28×16px、計時數字 64px、進度環 6px）。跨家族允許幾何不同（它是家族氣質的一部分），但各家族內部必須保持常量。
  3. 狀態色語義全域統一：timerActive 恆為「進行中」、timerPause 恆為「暫停/休息」，色相可換、語義不可換；完成回饋統一為「一次性、非迴圈、≤600ms」的輕動效（印章/波紋/金線/河豚鼓起/墨線收鋒等形式不同、重量相同）。
  4. 入版統一檢查清單：每個主題合入前過同一套門禁——文字對比度（正文 ≥4.5:1、大字與圖形 ≥3:1，用指令碼實測）、「減少動態效果」靜態方案完整、bubbleDensity/driftSpeed ≤1×、環境音預設關、選單欄圖示為 template、theme.json schema 校驗透過。本文件九套主題的對比度實測值已隨附，可直接作為驗收基準。
