## 初剪版與真機重錄說明（W3 實施註記）

初剪採用「分鏡畫面卡（真實 UI 截圖）+ 字幕」合成，鏡頭節奏按上表時間分配。需真機重錄的鏡頭：

- **S1 / S6**：需要真實桌面桌布與掛件小窗位置，headless 無法拍。
- **S2 / S3**：空格開始、計時滾動、水草成長動畫、選單欄小魚游動——需要真實桌面互動錄屏（可倍速後期壓短）。
- **S5**：音量滑桿的連續動畫與聲音切換手感，截圖序列只能示意。

可由初剪直接使用的鏡頭：**S4**（「這段時間」面板展開態，headless 截圖已覆蓋真實 UI）。

### 真機錄製指引（QuickTime）

1. 準備預置存檔：圖鑑 5/15、稱號「萌芽」段、本週有記錄（可用瀏覽器模式跑幾輪後匯出，再替換桌面存檔）。
2. QuickTime Player → 檔案 → 新建螢幕錄製 → 選「錄製大小」為 Retina 全畫布。
3. S2：空格開始 → 讓計時滾動幾秒（可倍速）→ 停在主視窗畫面。
4. S3：完成一輪後拍水草長高瞬間 + 圖鑑頁停留 0.5s。
5. S5：聲音面板海浪→咖啡館切換，手推音量滑桿。
6. S6：按 ⌘⇧A 收為掛件，定格在 logo + 地址幀 2s。
7. 後期按上表時間軸剪接，疊加 6 條字幕卡。
