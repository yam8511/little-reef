# v0.4 Release notes 定稿

> 來源：飛書物料定稿 docx/OQ8Qd9SaHokTnUxW7zCcSSIbncf（revision 5，2026-10-24）。
> **用途**：CHANGELOG.md 新增節 + GitHub Release 正文。
> **風格基準**：對照 CHANGELOG 0.3.0/0.2.x——中文、條目式、動詞開頭、無 emoji、只寫使用者可感知的行為。

## CHANGELOG.md 條目（寫入 CHANGELOG.md）

```markdown
## 0.4.0

- 新增「這段時間」回顧面板：本週、本月和累計的專注時長與輪數，還有一起度過的天數、圖鑑完成度和當前成長階段，展開就能看
- 統計只作正向記錄：不顯示連續打卡，沒有目標，也不提醒
- 設定裡新增「備份與恢復」：存檔可以一鍵匯出，換機或重新安裝前先備一份；匯入前會校驗，失敗不會影響當前存檔
- 存檔匯出再匯入，內容和原來完全一樣，圖鑑與總時長完整保留
- 掛件模式保持不變，統計只在主視窗展開檢視
```

## GitHub Release 正文（Release body，可帶連結與物料）

```markdown
這一版給「看得見的進步」和「資料安全」各加了一層：

- 「這段時間」回顧面板：本週、本月和累計的專注時長與輪數、一起度過的天數、圖鑑完成度、當前成長階段——展開就能看。它只做正向記錄：不顯示連續打卡，沒有目標，也不提醒。
- 「備份與恢復」：設定裡一鍵匯出存檔，換機或重新安裝前先備一份；匯入前會校驗，失敗不會影響當前存檔，成功匯入後一切如初。

官網新增中英對照與回顧面板介紹：https://reef.echovic.com

---

**下載**：little-reef-0.4.0-macos-arm64.dmg（需要 macOS 12 或更高版本，Apple 晶片）

已安裝的使用者會自動收到更新提示；也可以在選單欄圖示右鍵選「檢查更新」。
```

**兩條備註**：

1. 「內容和原來完全一樣」一句以 Task 3 往返無損驗收實際透過為前提——未透過則刪改此條（計劃 9.3 原則不變）。
2. 版本號與 DMG 檔名按實際構建產物替換；Release 正文中的更新提示機制描述以 CHANGELOG 0.2.2/0.2.3 既有行為為準。
