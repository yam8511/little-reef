# 小海底

簡體中文 | [English](README.en.md)

用專注時間養出一片小海底。每完成一輪專注，水草就長高一點，偶爾還會有魚、蝦或螃蟹來做客。這是一個安靜的桌面專注計時器，帶水族館、訪客圖鑑和 20 種背景音。

## 下載

適用於 Windows 10/11。到 [Releases](https://github.com/yam8511/little-reef/releases) 下載最新的 `app-setup-<版本>-amd64.exe`（ARM 電腦用 `arm64`）安裝。安裝後應用會定期檢查新版本，也可以在選單中選「檢查更新…」。

macOS 和 Linux 暫時沒有安裝包，可以[從原始碼構建](#從原始碼構建)。

## 功能

- **專注與休息**：預設專注 25 分鐘、休息 5 分鐘，可以在設定裡改，新時長從下一輪開始生效；支援開始、暫停、繼續、提前結束和可選的任務名，空格鍵開始或暫停。
- **水族館**：每完成一輪，水草長高，每三輪多一株植物；第一輪必定遇見小丑魚，之後每輪有三分之一的機會遇見訪客——4 種魚、6 種蝦、5 種蟹，沒見過的先來，15 位都見過之後老朋友會再來。圖鑑一直儲存。
- **餵魚**：每次休息可以喂一次，魚食下沉，吃剩的由蝦蟹撿走；中斷或離開也不會死魚，不扣裝飾。
- **背景音**：20 種背景音，除粉紅噪音是即時合成，其餘都是公共領域的錄音；每條可單獨調音量和開關。完成提示音可以單獨開關，靜音時仍有文字提示和系統通知。
- **桌面與選單欄**：桌面掛件、收起到選單欄、全域快捷鍵 `CmdOrCtrl+Shift+A`；選單欄的小魚專注時游動、暫停時停住，點開是快捷面板。系統開啟「減少動態效果」時動畫靜止，計時和聲音照常。
- **主題**：10 套海底皮膚；可以按時段自動切換（06:00 馬卡龍、10:00 賽璐璐、17:00 青綠江山、20:00 深海寫實），也可以每 30 分鐘從全部皮膚隨機輪換。
- **記錄**：「這段時間」面板顯示本週、本月和累計的專注時長與輪數、一起度過的天數、圖鑑進度和當前成長階段；只做正向記錄，沒有連續打卡和目標提醒。
- **設定與備份**：通用、外觀、快捷鍵、備份與恢復四個標籤頁；快捷鍵可以單獨錄製、停用或恢復預設，衝突會提示。「備份與恢復」把整個存檔匯出成帶版本號的 JSON，匯入前校驗，失敗時當前存檔不變。

## 存檔與計時

- 計時由 Go 後端負責，視窗隱藏或收進選單欄都不影響。
- 電腦休眠，或程式被系統掛起超過 5 秒，計時自動暫停，休眠時間不計入專注。
- 執行時每 30 秒自動儲存，正常退出和重要操作立即儲存；退出時暫停當前計時，重新開啟後保持靜音。
- 提前結束會記錄已投入的時間，但不增加成長；完成休息也不增加成長。
- 存檔是 `aquarium.json`，在 macOS 的 `~/Library/Application Support/小海底`；`-data-dir` 可以指定其他目錄。日記保留最近 1000 條，介面顯示最近 30 條。

## 從原始碼構建

需要 Go 1.27.3 或更高版本。介面全部是 MyGo 原生 UI（`ui.View`），不需要 Node.js，也沒有網頁前端。

```sh
CGO_ENABLED=0 go test ./...
CGO_ENABLED=0 go run .                            # 桌面版
go run -tags harness .                            # MCP 測試支架，見下文
CGO_ENABLED=0 go tool mygo build -sign=- -skip-notarize .   # macOS 應用和 dmg，輸出到 build/darwin-arm64
```

Go 二進位制透過 `//go:embed` 打包 `assets/themes` 的主題和 `assets/sounds` 的背景音；海底動畫在 `internal/reef`，用 MyGo 的 Painter 繪製，背景音用 MyGo 的 `audio` 包播放。更換背景音見 `build-sounds.sh`，更換圖示見 `go run . -export-icons`。

## 測試

`CGO_ENABLED=0 go test ./...` 覆蓋計時、存檔回滾、物種遇見順序、背景音總量、減少動態效果、快捷鍵校驗，以及用 `ui.Tester` 驅動的主視窗、掛件和托盤面板。

視窗上的測試可以交給 MCP 客戶端：`go run -tags harness .` 在 `http://127.0.0.1:8765/mcp` 啟動 [mygo-mcp](https://github.com/auron-labs/mygo-mcp) 支架，提供主視窗、窄視窗、首次啟動、掛件和托盤面板幾個無頭畫面，每個都用臨時存檔。倉庫裡的 `.mcp.json` 已經讓 Claude Code 連上它，可以檢視、點選、輸入和截圖。
